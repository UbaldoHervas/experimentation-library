# Publicación de ExperimentPy 0.1.0

Esta carpeta contiene el código y los archivos de distribución en `dist/`.
El nombre queda registrado al aceptar PyPI la primera subida; disponer de
los archivos localmente no lo reserva.

La distribución se publica mediante Twine usando la cuenta del propietario.
La autenticación de subida usa un token de PyPI. No añadas ese token al código,
al repositorio ni a los archivos de distribución.
